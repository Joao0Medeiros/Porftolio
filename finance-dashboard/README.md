# Fluxo Claro

Dashboard financeiro responsivo para acompanhamento de saldo, receitas, despesas, categorias, orcamentos e meta de reserva.

## Destaques

- Cadastro de receitas e despesas
- Indicadores principais recalculados automaticamente
- Grafico de fluxo de caixa sem dependencias externas
- Filtro e busca de transacoes
- Remocao de lancamentos
- Exportacao CSV
- Dados salvos no `localStorage`
- Tema claro/escuro com preferencia salva no navegador
- Layout responsivo para desktop e celular

## Tecnologias

- HTML5
- CSS3
- JavaScript

## Como abrir

Abra o arquivo `index.html` no navegador.
